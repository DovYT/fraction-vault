# סוכני הכספת DIGITAL – שעשועון השברים הגדול

משחק וובי לכיתה ד׳: שבר מדומה ↔ מספר מעורב בשלישים ובשישיות, בעזרת רצועות, פיצות והמחשות.
חמש משימות, חמש ספרות, כספת אחת – קוד הכספת: **16321**.

> DIGITAL · יפעת וייסמן קרמר | מובילה טכנו פדגוגיה

## הפעלה (למורה ולתלמידים)
- פותחים את הקישור בדפדפן Chrome. אין הרשמה, אין התקנה, אין שרת, אין שימוש ב־AI בזמן המשחק.
- ההתקדמות והשמות נשמרים **רק בדפדפן של אותו מחשב** (localStorage). כל מחשב הוא עותק עצמאי ולא נשלח שום מידע החוצה.
- רענון הדף לא מוחק התקדמות. כפתור „התחלת משחק חדש” (בראש המסך ובמסך הפתיחה) מאפס רק לאחר אישור.
- „הגדרות למורה”: מוזיקה, אפקטים, ביטול אנימציות, דילוג על הפתיח, מסך מלא, שעון מעודד (לא פוסל), איפוס, מצב הדגמה כיתתית (כתב גדול ומעבר חופשי בין משימות) והצגת פתרונות.
- בסיום: תעודה להדפסה. בחלון ההדפסה אפשר לבחור ביעד „שמירה כ־PDF”.

## פרסום
האתר הוא קובץ אחד סטטי: `index.html`.
1. **GitHub Pages** (הדרך שבה פורסם): ריפו ← Settings ← Pages ← Branch: `main`, Folder: `/ (root)`.
2. **Netlify**: גוררים את התיקייה (או את `index.html` בלבד) לדף https://app.netlify.com/drop.
3. **Vercel**: `vercel --prod` מתוך התיקייה (ללא build, Output Directory = `.`).
4. שיתוף ב־Google Classroom: מצרפים את כתובת ה־HTTPS כקישור.

## פיתוח
```bash
node build.mjs     # או ./build.sh – בונה index.html יחיד מתוך src/
node tests/check.mjs   # בדיקות תוכן ומתמטיקה
python3 -m http.server 8000   # תצוגה מקומית: http://localhost:8000
```
אחרי כל שינוי ב־`src/` מריצים build ומעלים (commit + push) את `index.html`. הכתובת נשארת זהה.

## היכן עורכים
| מה | איפה |
|---|---|
| חתימה, שם המותג, כותרות | `src/js/config.js` (`FV.SIGNATURE`, `FV.BRAND`, `FV.TITLE`) |
| קוד הכספת וספרות | `src/js/config.js` (`FV.DIGITS`) |
| טקסטי המנחה, רמזים („גלגל ההצלה”), הסברי מורה | `src/js/config.js` (`FV.HOST`, `FV.TASKS`) |
| תרגילי משימה 2, שורות משימה 3, קבוצות משימה 4, הזמנות ומלאי משימה 5 | `src/js/config.js` (`FV.T2`–`FV.T5`) |
| שמות מספרים בעברית | `src/js/math.js` (`FV.words`) |
| לוגיקת המשימות | `src/js/tasks.js` |
| מסכים, כספת, תעודה, הגדרות | `src/js/screens.js` |
| צלילים (מסונתזים ב־WebAudio, אין קבצי שמע) | `src/js/core.js` (`FV.audio`) |
| עיצוב האולפן | `src/css/main.css` |

סימון שברים בתוך טקסט: `[[5/3]]` שבר, `[[1 2/3]]` מספר מעורב, `{{2 × 6 + 2 = 14}}` ביטוי משמאל לימין.
חשוב: בשינוי הזמנות במשימה 5 יש לוודא שסך ההזמנות בשלישים שווה לסך המלאי (הבדיקה האוטומטית בודקת זאת).

## מקורות
המשחק נבנה בהשראת הקו הפדגוגי של חומרי ההוראה בכיתה (קיבוץ חלקים שווים לשלמים). כל הגרפיקה, הדמות והצלילים מקוריים. עמודי הספר והסרטון אינם חלק מהריפו.
